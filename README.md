## 🌟 Highlights & Bespoke Creative Engineering Features

### 1. 🌐 Natural Interactive 3D WebGL Engines (Three.js r128)
- **Teen Portal (`teen.html` & `teen-hero-3d.js`)**:
  - **Quantum Talent Core**: Multi-layered 3D faceted crystal mesh with physical materials, metallic roughness, and dual precessing wireframe gyro cages.
  - **Natural Drag-to-Rotate Physics**: Grab and drag the 3D core anywhere in 3D space with angular velocity, rotational momentum, and smooth friction damping ($0.94$).
  - **Click Energy Shockwave**: Clicking emits an expanding glowing shockwave ripple that expands outward through the geometry and cosmic dust motes.
  - **Volumetric Cosmic Particles**: 220 star motes floating with natural organic Brownian drift.
- **Enterprise Hub (`company.html` & `company-hero-3d.js`)**:
  - **Holographic 3D Global Talent Arc Network**: 3D Cyber Geosphere with wireframe latitude/longitude rings, dark ocean core, and beacon pins representing global tech hubs (SF, London, Mumbai, Bangalore, Singapore, Tokyo, Berlin).
  - **Quadratic Bezier Talent Arcs**: Streaming white data packets actively traveling across continents along great-circle trajectory arcs.
  - **Planetary Drag-to-Rotate**: Grab and spin the globe freely with natural spherical inertia and momentum.

### 2. 🧲 Magnetic Buttons & Raycast Spotlight Borders
- **Dynamic Mouse Spotlight Border Engine** (`.spotlight-card`):
  - Tracks cursor coordinates (`--mouse-x`, `--mouse-y`) to generate dynamic, moving border halo gradients inspired by Linear and Raycast.
- **Magnetic Button Physics** (`.magnetic-btn`):
  - CTAs physically gravitate toward the cursor when hovered with spring physics damping.
- **Multi-Tier 3D Perspective Card Tilt**:
  - Internal card layers have tiered z-depths (`translateZ(48px)` for badges, `translateZ(34px)` for titles, `translateZ(22px)` for body copy) creating genuine physical parallax.

### 3. 🎞️ Organic Film Grain & Visual Refinement
- Ambient micro-noise grain overlay (`opacity: 0.022`) eliminates the artificial "AI generated plastic" look and gives the layout a bespoke, cinematic tactile feel.
- High-contrast typography wrapped in **Plus Jakarta Sans** and **Inter**.

### 4. ⚡ High-Performance Scroll Engine & Live Counters
- Hardware-accelerated CSS animations (`IntersectionObserver` at `0.12` threshold) with automatic memory unobserving.
- Value-increment ticker calculation animating metrics smoothly ($1 - (1 - \text{progress})^4$ quintic easing) from 0 to `15,000+ Verified Talents`.

### 5. 🧮 Built-In Real-Time Interactive Simulators
- **Teen Pocket Money Calculator**: Live hours slider (2 to 20 hrs/wk) computing weekly, monthly, and annual earnings.
- **Enterprise Project ROI Estimator**: Volume slider computing direct capital saved against legacy agency retainers.

## 🚀 How to Upload to GitHub & Go Live in 60 Seconds (Free)

### Step 1: Initialize Git and Commit
```bash
git init
git add .
git commit -m "feat: complete production Funngro 2-page platform with natural 3D interactions"
```

### Step 2: Push to GitHub
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/funngro-assessment.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub &rarr; **Settings** &rarr; **Pages**.
2. Select **Branch**: `main`, Folder: `/ (root)`.
3. Click **Save**.
4. Your website is instantly live at `https://YOUR_USERNAME.github.io/funngro-assessment/`!
